## Environment

Toolchain (checked in M0): GCC `16.2.1`, Meson `1.12.1`, Ninja `1.13.2`, pkgconf `3.0.7`;
WPE WebKit `2.54.1-2` (`wpe-webkit-2.0`, `wpe-platform-2.0` and `wpe-platform-wayland-2.0`
all report `2.54.1`), GLib `2.90.1`, bubblewrap `0.13.0`; nothing had to be installed.
Kernel `7.2.9-arch1-1`, niri `26.04-1`, Mesa `1:26.2.4-1`. One built-in output,
1920×1200 at scale 1.0; benchmark viewport 950×1188 logical pixels. Not tested:
multi-monitor and fractional scaling (unavailable, M6-07). An xdg maximized state was
observed on 2026-10-16 (`niri msg action maximize-window-to-edges`: 1920×1200 with
`maximized=1`, restored to 950×1188, exit 0; one run, not in the probe).

## Observations later milestones start from

- **Sandbox (M3-05):** the web process runs under bubblewrap with `NoNewPrivs: 1`,
  `Seccomp: 2` and its own mount, PID, user and network namespaces. The network and UI
  processes are not confined the same way in the stock build. This is an observation,
  not a sandbox audit.
- **Google Scholar (M2-08):** one agent-run search and the maintainer's guided session
  (search, opening a result, scrolling) showed normal results with the default identity
  and fresh ephemeral sessions; no challenge appeared and none was cleared. This does not
  show lasting compatibility; that is checked with persistent profiles in M2. The
  missing glyphs in its language menu are deferred to roadmap M3-10 (D-11).
